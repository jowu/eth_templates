# eth_templates

These are templates I use for my work/study at ETH D-EAPS. 

None of these are official ETH templates and should not be construed as such. 
The ETH and D-EAPS logos may only be used if you are student or are employed at ETH.

## editing_pkg

A small package with utility commands and editing hacks that make it easier to format
the final LaTeX output to meet publishing standards.

## reports

A simple, single-file template for reports and short articles. 

## thesis

A full template supporting the D-EAPS formatting requirements for BSc and MSc theses.
